## ✏️ ওয়েবসাইট আপডেট করার নিয়ম

### সহজ পদ্ধতি (GitHub ওয়েবসাইট থেকে সরাসরি):
1. [github.com/rezwanahmed399/saptasur](https://github.com/rezwanahmed399/saptasur) এ যান
2. যে ফাইলটি পরিবর্তন করতে চান সেটিতে ক্লিক করুন
3. পেন্সিল (✏️) আইকনে ক্লিক করুন
4. পরিবর্তন করুন
5. "Commit changes" বোতামে ক্লিক করুন
6. কয়েক মিনিটের মধ্যে ওয়েবসাইট আপডেট হয়ে যাবে!

### উন্নত পদ্ধতি (Git দিয়ে):
```bash
git add .
git commit -m "নতুন সংবাদ যোগ করা হয়েছে"
git push
```
